Research direction

AI Agent Security

Mengyuan Li’s research on AI agent security uses trusted execution environments (TEEs) and runtime monitoring to observe agent execution and to build trusted infrastructure for LLM systems and AI agents. The goal is agent backends that remain observable, trustworthy, and resilient when they run on shared cloud infrastructure and handle sensitive data.

Topics: secure AI agents · agent runtime monitoring · TEEs for AI agents · trusted infrastructure for LLM systems · trustworthy agent execution

Perspective

This direction focuses on monitoring and protecting agent execution rather than only verifying final outputs. It brings together TEEs, confidential computing, and runtime observation to support trustworthy LLM systems and agentic infrastructure.

Foundations

TEE and Confidential Computing provide mechanisms for isolated execution, protection of agent state, and secure multi-tenant infrastructure.

Verifiable AI is related because agent systems also need execution integrity, auditability, and trustworthy model-serving pipelines.

Challenges

Key open problems include:

  • observing agent execution with TEEs or runtime monitoring;
  • isolating tool execution;
  • protecting long-lived memory and secrets;
  • building trusted infrastructure for LLM systems and agents;
  • defending agent backends against cloud- and hardware-level leakage.
